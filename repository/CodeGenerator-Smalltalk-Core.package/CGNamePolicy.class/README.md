I am the single definition of legal Smalltalk names for the CodeGenerator framework. I turn arbitrary property/definition strings into valid class names (validate, camelCase underscores, singularize with a documented exception list, prefix) and instance-variable names, and I answer whether a candidate is a valid identifier. I am stateless apart from an optional prefix, so my name methods are pure functions (collision rule: last-wins - two inputs that normalize to the same identifier resolve to the same name).
