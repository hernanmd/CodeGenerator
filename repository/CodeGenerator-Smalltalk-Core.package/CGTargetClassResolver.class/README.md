I am the single authority for resolving the target class of a generation run from a base name plus an optional prefix (defect F6 as a first-class policy, not a side-effecting setter). When a prefix is active I resolve or create ONLY the prefixed name and never mutate an unrelated unprefixed class of the same base name. When no prefix is active I reuse an existing class of that exact name or create it in the configured category. I signal CGGenerationError, naming the intended class, when creation fails, leaving no partial state.
